# Thesis Source Notes

The files in this directory preserve the original undergraduate thesis source as supplied for archival and reproducibility purposes.

## Known issue

`main.tex` contains:

```tex
\include{abbreviations}
```

but no `abbreviations.tex` file was included in the archived project materials available for this repository.

This has intentionally **not** been reconstructed inside the archival source. Any repair needed for compilation will be made separately in the journal/preprint manuscript workflow so that the original source remains transparent.

## Scope

This directory is not the journal-ready manuscript. It contains the original thesis source, figures, and bibliography. Revised materials for preprint and journal submission will be maintained separately.
