# Supplementary material package

The file `manuscript/supplementary_material.tex` is the current supplementary manuscript.

It contains:
- Supplementary Methods S1 — complete core search strategy and supplementary-search description.
- Supplementary Table S1 — full 34-study characteristics and extracted-findings table.
- Supplementary Tables S2-S5 — item-level JBI appraisal for RCT, cohort, cross-sectional, and quasi-experimental studies.
- Supplementary Note S1 — overlapping-cohort and companion-report handling.

This keeps granular extraction and appraisal detail outside the main paper, preserving the target journal's main table/figure allowance.

The PRISMA record counts remain intentionally unresolved until the complete record library is available for deduplication.
