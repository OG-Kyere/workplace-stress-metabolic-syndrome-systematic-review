# OEM submission set

This folder contains the reader-facing files intended for the eventual *Occupational and Environmental Medicine* submission.

## Primary files

- `oem_submission_main.tex` — main manuscript
- `oem_submission_tables.tex` — main Tables 1--3
- `oem_submission_supplement.tex` — supplementary material
- `oem_submission_references.bib` — bibliography
- `cover_letter_oem.md` — cover letter
- `oem_author_front_matter.md` — author/title-page information
