# OEM submission file map

| Submission component | Source file |
|---|---|
| Scientific manuscript body | `manuscript/main.tex` |
| OEM abstract/front matter | `manuscript/oem_submission_wrapper.md` |
| Author details/declarations | `manuscript/oem_author_front_matter.md` |
| Key messages | `manuscript/oem_key_messages.md` |
| Main tables | `manuscript/tables_main.tex` |
| Evidence-map figure | `manuscript/evidence_map_figure.tex` |
| Final PRISMA figure | to be generated after count freeze |
| References | `manuscript/references_verified.bib` |
| Supplement | `manuscript/supplementary_material.tex` |
| Cover letter | `manuscript/cover_letter_oem.md` |
| Effect verification audit | `data/effect_estimate_verification_status.csv` |
| Freeze reference | `freeze/non-prisma-2026-10-06-v2` |

This file map is for assembly control only and should not itself be uploaded to the journal.
