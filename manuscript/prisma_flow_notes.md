# PRISMA figure status

`manuscript/prisma_flow_template.tex` is intentionally a **template**, not the final PRISMA figure.

It contains placeholders for:
- database and supplementary records identified;
- duplicates removed;
- records screened/excluded;
- reports sought/not retrieved;
- full texts assessed;
- exclusion counts by reason;
- included studies and reports.

Do not replace `TBD` values manually from memory.

The final values should be generated from the completed record-level screening log described in `docs/prisma_completion_protocol.md`.
