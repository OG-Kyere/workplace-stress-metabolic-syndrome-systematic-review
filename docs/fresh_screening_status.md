# Fresh Search Screening — Verified Candidate Set

The fresh workplace-focused search has now identified **23 studies that satisfy the working title/abstract-level inclusion rule**.

This is not yet the final PRISMA-included count.

## Why these are only "include candidates"

Before final inclusion, each record still requires:

1. duplicate checking;
2. full-text confirmation of population, exposure/intervention, outcome, and completed-study status;
3. confirmation that multiple papers do not report the same underlying cohort/outcome in a way that would double-count evidence;
4. final design classification;
5. risk-of-bias/quality appraisal.
