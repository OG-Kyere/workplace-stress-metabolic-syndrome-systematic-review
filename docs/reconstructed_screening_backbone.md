# Known-record screening reconstruction

This file documents the subset of screening history that can be reconstructed from the repository **without inventing missing PRISMA data**.

## Contents

- 34 records from `data/verified_include_candidates.csv`, representing the current included-study pool.
- Historical records from `data/path_A_screening_decisions.csv` that were excluded under the revised workplace-focused eligibility criteria.
- Historical "retain" rows that correspond to current included studies are not duplicated.

## Important boundary

This is **not** a PRISMA screening log and must not be used to calculate records identified, duplicates removed, title/abstract exclusions, reports sought, or reports assessed.

The repository still lacks the complete raw search export and original record-level screening history needed for those counts.

## Purpose

The reconstruction is useful for:
1. confirming that known historical exclusions do not conflict with the current 34-study pool;
2. preserving the exclusion reasons already established during re-screening;
3. providing a seed file for later reconciliation if the raw search export is recovered;
4. distinguishing genuinely missing search-history data from study-level evidence that has already been resolved.

Generated from repository evidence on 10 October 2026.
