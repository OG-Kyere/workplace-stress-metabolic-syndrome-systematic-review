# PRISMA Lock Checklist

Before the review is submitted, all items below must be completed.

- [x] Review question and workplace scope defined.
- [x] Publication period defined (2015–2026).
- [x] Core PubMed/MEDLINE strategy archived.
- [x] Supplementary search concepts documented.
- [x] Eligibility criteria operationalized.
- [x] Study-design eligibility defined.
- [x] MetS/component outcome rule defined.
- [x] Companion-report and overlapping-cohort rule defined.
- [x] Active study pool assembled.
- [x] Study characteristics extraction initiated.
- [x] Effect-estimate extraction initiated.
- [x] Design-specific JBI appraisal framework implemented.
- [ ] Export all records returned by the final database search.
- [ ] Preserve DOI/PMID/title for every retrieved record.
- [ ] Merge supplementary-search records with the database export.
- [ ] Deduplicate records.
- [ ] Freeze title/abstract screening decisions.
- [ ] Freeze full-text eligibility decisions and exclusion reasons.
- [ ] Link companion reports to parent studies.
- [ ] Freeze final included-study and included-report counts.
- [ ] Populate PRISMA 2020 flow diagram.
- [ ] Update Abstract, Methods and Results with the frozen counts.
- [ ] Freeze reference list.
